# Передача проекта CoolChess другому агенту

Отвечай пользователю по-русски. Проект — статический лендинг шахматной школы CoolChess. Пользователь правит сайт по частям и проверяет изменения локально. **Не публикуй сайт и не переключай выпуск на сервере без отдельного запроса.**

## Как запустить

- В корне проекта выполни `python -m http.server 4173` и открой `http://localhost:4173/`.
- Сборка и зависимости npm не нужны. Основные файлы: `index.html`, `main.js`, `styles.css`, `refinements.css`, `hero.css`, `audience.css`, `quiz.css`, `assets/`, `docs/`.
- Текущее состояние зафиксировано в Git. У репозитория нет настроенного remote; для переноса истории приложен Git bundle в архиве передачи.
- Исходный дизайн — `Chess 2.fig` (около 950 МБ). Он не входит в Git, но включён в архив передачи отдельно от файлов сайта. В архиве есть `TRANSFER.md` с шагами восстановления.

## Реализованные части

- Приведены к макету секции о занятиях, программах по возрасту и другие разделы страницы. Адаптивные исправления находятся в `refinements.css` и `audience.css`.

## Ограничения и следующие шаги

- Шрифт TT Firs Neue Variable из макета не вложен в проект; браузер использует запасной. Из-за этого начертание и переносы строк могут отличаться.
- Для пяти образовательных программ в макете предусмотрены действия просмотра и скачивания PDF. Исходные PDF программ не найдены; текущие строки раскрываются через `<details>`. Не добавляй фиктивные ссылки.
- Перед запуском на основном домене надо проверить платежи тестовой транзакцией и форму AlfaCRM на целевом домене.
- Файл `ssh_creds.txt` содержит серверный доступ, исключён из Git и архива передачи. Не выводи его содержимое и не добавляй в коммиты или архивы. `tmp/` и `tools/` — локальные временные материалы и тоже исключены.
- По явному запросу пользователя 3 октября 2026 года опубликованы все текущие изменения на `https://secretinc.ru/`. Активный выпуск — `/var/www/secretinc.ru/releases/20261003-1f418de`, ссылка `current` переключена атомарно. Прежний выпуск `/var/www/secretinc.ru/releases/20261003-d077dae` сохранён для возврата. Перед переключением сверены контрольные суммы всех 80 публичных файлов, после — выдача Nginx. Объединённый блок лицензии/программ и фотографии детей проверены по публичному адресу при 1440 и 390 px; изображения загружаются, горизонтального переполнения и ошибок JavaScript нет. SSH-ключ сервера изменился; пользователь подтвердил ED25519 `SHA256:2Lc2FQwO4/gxkXoygtffkzh8pLlBwZCpsAeNtXafSPc`. Для подключения закреплён именно этот ключ в локальном временном `tmp/deploy-known-hosts`; общий `~/.ssh/known_hosts` не менялся. Не деплой новые изменения без явного поручения пользователя.
