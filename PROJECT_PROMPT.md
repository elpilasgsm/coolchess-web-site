# Передача проекта CoolChess другому агенту

Отвечай пользователю по-русски. Проект — статический лендинг шахматной школы CoolChess. Пользователь правит сайт по частям и проверяет изменения локально. **Не публикуй сайт и не переключай выпуск на сервере без отдельного запроса.**

## Как запустить

- В корне проекта выполни `python -m http.server 4173` и открой `http://localhost:4173/`.
- Сборка и зависимости npm не нужны. Основные файлы: `index.html`, `main.js`, `styles.css`, `refinements.css`, `hero.css`, `audience.css`, `quiz.css`, `assets/`, `docs/`.
- Текущее состояние зафиксировано в Git. У репозитория нет настроенного remote; для переноса истории приложен Git bundle в архиве передачи.
- Исходный дизайн — `Chess 2.fig` (около 950 МБ). Он не входит в Git, но включён в архив передачи отдельно от файлов сайта. В архиве есть `TRANSFER.md` с шагами восстановления.

## Реализованные части

- Пересобран первый экран по актуальному `Frame 2` (1440 × 880) из макета: навигация, заголовок, изображения, видео тренера и нижние табы. Его стили — в `hero.css`.
- Приведены к макету секции о занятиях, программах по возрасту и другие разделы страницы. Адаптивные исправления находятся в `refinements.css` и `audience.css`.
- Блок «Подберём обучение за 30 секунд» сделан по `Main → Frame 48 → Вопрос 1 → Вопрос 2 → Вопрос 3 → Итог`. Он работает внутри страницы, без модального окна. Вопросы и варианты ответов перенесены из локального `.fig`:
  1. «Кто будет заниматься?» — ребёнок 4–6 лет; ребёнок 7–12 лет; подросток; взрослый 18+.
  2. «Какой сейчас уровень?» — новичок; знает правила; умеет играть; турнирный уровень.
  3. «Какая цель?» — научиться играть; развивать мышление; играть в турнирах; получить разряд.
- После третьего ответа показывается «Начнём с пробного урока» и встроенная форма действующей AlfaCRM. Есть ссылка для открытия формы отдельно. Стили блока — в `quiz.css`, логика — в конце `main.js`, исходные изображения — `assets/quiz-king.png` и `assets/quiz-pawn.png`.
- Другие кнопки записи используют ту же форму AlfaCRM: на локальном и демонстрационном доменах открывают её напрямую, на `coolchess.ru` предусмотрено встроенное окно.
- Тарифы 25, 45 и 60 минут и пакеты заданы в `main.js`. Оплата отправляет форму на PayKeeper. Реальный платёж не проводился.

## Что проверено

- Блок подбора просмотрен при ширине 1440 и 390 px. На узком экране горизонтальной прокрутки нет.
- Проверен переход через все три вопроса. Встроенный iframe AlfaCRM загрузился локально и показал поля записи. Заявка не отправлялась.
- Ранее проверены адаптивный первый экран, меню, секции и открытие окна оплаты. Платёж не отправлялся.
- `node --check main.js` и `git diff --check` прошли после изменений блока.

## Ограничения и следующие шаги

- Шрифт TT Firs Neue Variable из макета не вложен в проект; браузер использует запасной. Из-за этого начертание и переносы строк могут отличаться.
- Для пяти образовательных программ в макете предусмотрены действия просмотра и скачивания PDF. Исходные PDF программ не найдены; текущие строки раскрываются через `<details>`. Не добавляй фиктивные ссылки.
- Перед запуском на основном домене надо проверить платежи тестовой транзакцией и форму AlfaCRM на целевом домене.
- Файл `ssh_creds.txt` содержит серверный доступ, исключён из Git и архива передачи. Не выводи его содержимое и не добавляй в коммиты или архивы. `tmp/` и `tools/` — локальные временные материалы и тоже исключены.
- Сайт уже размещался на демонстрационном `secretinc.ru`, но последние локальные изменения туда не отправлялись. Не деплой без явного поручения пользователя.
