# CoolChess

Новая локальная версия сайта по макету `Chess 2.fig`.

## Запуск

В папке проекта:

```bash
python -m http.server 4173
```

Откройте [http://localhost:4173/](http://localhost:4173/).

## Запись и оплата

- Кнопки «Записаться на пробный урок» используют прежнюю форму AlfaCRM: `https://coolchess.s20.online/common/1/form/draw?id=1`. На локальном и демонстрационном доменах форма открывается напрямую, на основном — в окне внутри страницы. После трёх вопросов подбора встроенная форма записи показана прямо в блоке.
- Оплата пробного занятия за 500 ₽ доступна только в разделе тарифов: через карточку «Пробное занятие — 500 ₽» и общий список услуг окна оплаты. После оплаты менеджер связывается с клиентом и согласует время.
- Тарифы 25, 45 и 60 минут сверены с прежним сайтом. Выбранный пакет передаётся через HTML-форму методом POST на действующий адрес PayKeeper `https://coolchess1.server.paykeeper.ru/create/` с полями `service_name`, `sum`, `clientid`, `client_email`, `client_phone`.
- Перед переходом к оплате требуются ФИО, email, телефон и три согласия. Юридические документы скопированы с действующего сайта в `docs/`.
- Ссылка «Войти» ведёт в действующий кабинет AlfaCRM.

Внешнюю оплату не завершали тестовой транзакцией. Проверены сумма и контакты в перехваченном локально POST без отправки в PayKeeper. Перед запуском на основном домене нужно проверить полный путь с тестовым платежом, появление оплаты и контактов клиента в PayKeeper и получение уведомления менеджером; встроенную форму AlfaCRM нужно проверить на основном домене. Автоматическая передача оплаты в AlfaCRM и настройка уведомлений PayKeeper не входят в статический сайт.

Оригинальный `.fig` занимает около 950 МБ и остаётся в рабочей папке, но не включён в Git. Для сайта экспортированы и оптимизированы изображения из этого файла.

Для передачи проекта на другой компьютер см. [TRANSFER.md](TRANSFER.md). Контекст и текущие ограничения для следующего агента описаны в [PROJECT_PROMPT.md](PROJECT_PROMPT.md).

## Демонстрационный сервер

Сайт размещён по адресу [https://secretinc.ru/](https://secretinc.ru/) на Nginx. Конфигурация сервера сохранена в `deploy/secretinc.ru.nginx`, файлы сайта — в `/var/www/secretinc.ru/current` (ссылка на каталог выпуска). Сертификат самоподписанный, поэтому браузер предупредит о недоверенном издателе; для публичного запуска его следует заменить на сертификат доверенного центра. Доступы к серверу в Git не включены.
