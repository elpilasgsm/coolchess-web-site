# Перенос CoolChess на другой компьютер

Архив `coolchess-handoff-2026-10-03.zip` содержит:

- `site/` — готовые файлы сайта на момент коммита;
- `coolchess-history.bundle` — полную историю Git для продолжения работы;
- `Chess 2.fig` — исходный макет Figma, исключённый из Git из-за размера.

## Восстановление

1. Распакуйте архив на новом компьютере.
2. Если нужен Git с историей, выполните `git clone coolchess-history.bundle coolchess-site` и скопируйте `Chess 2.fig` в полученную папку. Если история не нужна, используйте папку `site/` и положите `.fig` рядом с `index.html`.
3. В папке сайта запустите `python -m http.server 4173` и откройте `http://localhost:4173/`.
4. Передайте новому агенту файл `PROJECT_PROMPT.md` как контекст проекта. Он находится в папке сайта.

Архив не содержит серверные учётные данные. У репозитория нет настроенного Git remote. Изменения сайта на сервер в рамках этой передачи не отправлялись.
